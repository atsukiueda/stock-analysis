# Part 1. Industry Overview

## 1. Basic Information

### Overview

SEMICONDUCTOR Industryは、半導体デバイスの設計・製造・検査・組立・材料・製造装置・関連サービスを提供する企業群で構成される。

Knowledge Baseでは、完成した半導体デバイスだけではなく、半導体バリューチェーン全体を対象とする。

### Key Characteristics

- Technology Sectorの中核Industry
- 長期成長性が高い
- 景気循環性が強い
- 設備投資サイクルの影響が大きい
- 日本企業は装置・材料・検査・精密加工に強みを持つ
- 投資判断はIndustry単位ではなくSubSector単位で行う

# Part5 Industry Intelligence（業界インテリジェンス）

## 5.1 Industry Cycle（業界サイクル）

### 5.1.1 Purpose（目的）

Industry Cycle（業界サイクル）は、半導体Industry（半導体業界）が現在どの事業環境にあるかを評価するためのKnowledgeである。

本Knowledge Baseでは、Industry Cycleを株価・出来高・Relative StrengthなどのMarket Sentiment（市場センチメント）では判定しない。

Industry Cycleは、以下のFundamental Evidence（実体経済・事業データ）から判定する。

- Demand（需要）
- Supply（供給）
- Inventory（在庫）
- CapEx（設備投資）
- Revenue（売上）
- Margin（利益率）
- Company Guidance（企業ガイダンス）
- Industry Statistics（業界統計）

---

### 5.1.2 Cycle Phases（サイクル局面）

| Phase | 日本語 | Definition |
|---|---|---|
| Contraction | 収縮局面 | 需要減速、在庫増加、利益率低下が進む局面 |
| Bottoming | 底打ち局面 | 悪化は続くが、在庫・受注・ガイダンスに改善兆候が出る局面 |
| Recovery | 回復局面 | 売上・受注・利益率の改善が確認される局面 |
| Expansion | 拡大局面 | 需要・設備投資・利益率が同時に強い局面 |
| Peak | ピーク局面 | 高稼働・高利益率だが、過熱や反転リスクが高まる局面 |
| Correction | 調整局面 | 需要鈍化・受注減速・在庫増加が始まる局面 |

---

### 5.1.3 Observation Framework（観測フレームワーク）

| Item | Content |
|---|---|
| Observation Category（観測カテゴリ） | Demand / Supply / Financial / Industry Statistics |
| Observation Type（観測種別） | Quantitative / Qualitative |
| Main Observations（主な観測項目） | 売上成長率、営業利益率、在庫回転率、CapEx、ガイダンス |
| Data Source（データソース） | J-Quants、決算説明資料、有価証券報告書、WSTS、SEMI、SIA、JEITA |
| Acquisition Method（取得方法） | API、IR資料取得、Research Sheet登録 |
| Update Trigger（更新契機） | 決算発表、業界統計更新、会社ガイダンス変更 |
| Operational Feasibility（運用可能性） | Medium |
| Proxy Candidate（代替指標候補） | Industry Cycle Score、Inventory Pressure Score、Equipment Demand Score |
| Source Authority（情報源の権威性） | Tier1 / Tier2 |
| Verification Requirement（検証要件） | 複数Evidenceによる確認必須 |

## 3. Evidence Notes（根拠メモ）

### AI / Data Center（AI・データセンター）

**Fact**

WSTSは、2025年の市場拡大について、AI向けデータセンターを支えるLogic ICとMemory ICの伸びを主要因としている。2026年もMemory ICとLogic ICが市場拡大を牽引する見込みとされている。:contentReference[oaicite:0]{index=0}

SEMIも、AI・データセンター需要に対応するため、Memory supplierがHBMや先端ノード対応へ投資していることを示している。:contentReference[oaicite:1]{index=1}

**Inference**

AI / Data Centerは、Memory、Logic、Equipment、Materials、EDAに広く伝播する中核Demand Driver候補。

**Initial Classification**

Tier1 Candidate

---

### Automotive（自動車）

**Fact**

IDCは、Automotive Semiconductor Market（車載半導体市場）について2025年成長を予測している一方、Industrial Semiconductor Market（産業向け半導体市場）は2025年前半に回復したと述べている。:contentReference[oaicite:2]{index=2}

一方で、Soitec CEOはAutomotive向けチップ需要について、在庫調整やEV展開の鈍さから2025年末まで回復しにくい可能性を指摘している。:contentReference[oaicite:3]{index=3}

**Inference**

Automotiveは長期的には重要な需要ドライバーだが、短中期では在庫調整・EV販売動向・地域差の影響が大きい。

**Initial Classification**

Tier1 or Tier2 Candidate  
要追加Evidence

---

### Industrial（産業機器）

**Fact**

IDCはIndustrial Semiconductor Marketが2025年前半に回復したと述べている。:contentReference[oaicite:4]{index=4}

**Inference**

IndustrialはAnalog、Power、MCU、Sensorへの影響が大きいが、AI / Data Centerほど半導体市場全体を押し上げるドライバーかは追加検証が必要。

**Initial Classification**

Tier2 Candidate

---

### Smartphone / PC（スマートフォン・PC）

**Fact**

JEITA由来の市場見通しとして、2025年はAI搭載PC・スマートフォンの普及が買い替え需要を押し上げる可能性が示されている。:contentReference[oaicite:5]{index=5}

**Inference**

Smartphone / PCは市場規模として重要だが、成熟市場であり、成長ドライバーというよりCycle Driver（サイクル要因）として扱うべき可能性がある。

**Initial Classification**

Tier2 Candidate  
Cycle Driver扱いを検討
