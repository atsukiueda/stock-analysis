## Purpose

This dictionary maps project-specific concepts to their governing source and relationship. It does not define schemas, business rules, models, or investment concepts independently.

| Concept | Relationship / use | Canonical source |
|---|---|---|
| Knowledge Base | Curated upstream knowledge and provenance | Knowledge Base Rules |

| Catalog | Controlled organization of knowledge for downstream use | Project Constitution dependency path |
| DDL | Downstream structural representation of governed knowledge | Project Constitution dependency path |
| Entity | Application-level representation linked to data structure | Project Constitution dependency path |

| Decision Engine | Decision rationale layer downstream of ML or rules | Model Governance / Project Constitution |
| Advisor | Advisory output layer downstream of Decision Engine | Model Governance / Project Constitution |

## Boundary

This dictionary is navigational. If an entry conflicts with a linked canonical source, the canonical source controls. New concepts require an identified governing source before this index can list them as governed concepts.
